# Вступительный комикс «Словопад»

Порядок: 01 → 02 → 03 → 04 → 05 → первая глава. Все пять кадров — отдельные непрозрачные RGB PNG 1920×1080 (16:9). Текст уже встроен в изображения; поверх его повторно не рисовать.

Альтернативных формулировок нет. Переносы строк композиционные; многоточие изображено тремя точками. В кадрах 2–3 отдельные буквы/руны внутри сцены — художественный эффект, а не дополнительная реплика.

Текст визуально сверен со сценарием. Контрастная тёмная антиква на светлом пергаменте. Кадр 3 наиболее насыщен текстом: показывать по клику без автотаймера, чтобы игрок успевал прочитать. Сохранять весь кадр в 16:9 без crop; при другом отношении сторон использовать поля. Кнопки перехода/пропуска добавляет игра отдельно, вне текстовых областей.

Сова сохраняет узнаваемые коричневые перья, кремовую грудку и янтарные глаза. Волшебник — тёмный капюшон, угловатые плечи, посох с разломанным полумесяцем. Цветовая дуга: живой тёплый мир → тревожные сине-фиолетовые руины → исчезновение → надежда → путешествие.
