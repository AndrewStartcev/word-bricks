# Запрос дизайнеру — UI pass 01

Дата: 2026-09-05

## Контекст

Основные графические ассеты лесной главы уже подключены. Меню, выбор уровней, пауза, победа, поражение и настройки сейчас собираются нативно в Godot через `Control`, `Button`, `PanelContainer`, `Label` и `StyleBoxFlat`.

Новые PNG-панели и кнопки **пока не нужны**.

По итогам текущего прохода выявлен один реальный недостающий production-ресурс: **встроенный игровой шрифт с кириллицей**.

## Задача

Подобрать и положить в проект один font family, который визуально подходит утверждённой игре:

- уютный casual game;
- мягче обычного интерфейсного sans-serif;
- не comic / не детский мультяшный;
- высокая читаемость букв внутри плитки 40–46 px;
- хорошая читаемость HUD и кнопок;
- полноценная кириллица;
- разрешено встраивание и распространение внутри бесплатной browser-game.

Визуальный ориентир по характеру: **Rubik / Nunito**, но можно предложить лучше, если он подходит текущей графике.

## Нужные файлы

Положить строго сюда:

```text
godot/assets/fonts/
├── game_regular.ttf
├── game_semibold.ttf
└── game_bold.ttf
```

Если выбран variable font и он корректно работает в Godot/Web, допустим один файл:

```text
godot/assets/fonts/game_variable.ttf
```

Но обычные отдельные веса предпочтительнее для предсказуемого Web-экспорта.

## Веса и назначение

- `Regular` — вторичный текст, подписи, подсказки;
- `SemiBold` — меню, HUD, кнопки, названия уровней;
- `Bold` — буквы на игровых плитках и крупные заголовки.

## Обязательная проверка кириллицы

Перед сдачей проверить строку:

```text
АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ
абвгдеёжзийклмнопрстуфхцчшщъыьэюя
```

Особенно: `Ё ё Й й Ъ Ы Ь Э Ю Я`.

## Лицензия

Вместе со шрифтом добавить:

```text
godot/docs/licenses/font_game.txt
```

В файле указать:

- название шрифта;
- автор / foundry;
- лицензию;
- официальный source URL;
- разрешение на embedding / redistribution;
- если требуется attribution — точный текст attribution.

Не использовать шрифт с неясной лицензией или файл из случайного font-сайта.

## Что НЕ нужно делать

Не рисовать отдельно:

- PNG-кнопки;
- UI-панели;
- текстовые заголовки картинками;
- glow;
- тени интерфейса;
- pause/victory/defeat окна одним изображением.

Это уже реализуется нативно в Godot и должно оставаться адаптивным.

## Что отписать после загрузки

В `godot/docs/designer_notes.md` добавить секцию `UI pass 01 / Font` и указать:

1. точные пути файлов;
2. название family;
3. соответствие файлов весам;
4. лицензию;
5. результат проверки кириллицы;
6. рекомендуемые размеры:
   - tile letter;
   - HUD;
   - button;
   - heading.

После этого разработчик подключит font resources вместо временного system font stack.
