# Словопад / Word Bricks

Ремейк игры «Словопад» на Godot 4 для Яндекс Игр.

Статус: **pre-production / gameplay prototype**.

Главный принцип ремейка: игрок заранее видит текущее слово и понимает, какую букву нужно провести в очищаемую линию. Словесная механика должна влиять на решение при размещении каждой фигуры, а не работать как пассивный прогресс-бар.

## Структура

- `docs/GAME_DESIGN.md` — дизайн-документ;
- `docs/ASSET_PLAN.md` — план будущих визуальных и аудио-ассетов;
- `docs/PROTOTYPE_TEST_PLAN.md` — критерии проверки core loop;
- `godot/` — рабочий Godot-проект.

Старый HTML/JS-архив и утверждённый gameplay-макет в репозиторий не добавляются. Они используются только как контекст разработки вне Git.

## Утверждённый формат

- Desktop-first, 16:9;
- базовое разрешение: 1600×900;
- Godot 4, Compatibility / WebGL2;
- русский язык;
- UI без логотипа во время геймплея;
- панели с небольшим радиусом, без чрезмерно «мобильных» скруглений.

## Текущий этап

Сначала доводим до рабочего состояния core loop без production-ассетов. Когда конкретный ассет станет нужен для следующего этапа, формируется отдельное ТЗ для AI-дизайнера с точным размером, форматом, прозрачностью и ограничениями.
