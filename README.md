# Словопад / Word Bricks

Ремейк старой HTML/JS-игры «Словопад — собери 3 слова» на Godot 4 для Яндекс Игр.

Статус: **pre-production / gameplay prototype**.

Главный принцип ремейка: игрок заранее понимает, какое слово и какую букву он собирает. Нужная буква должна попасть в очищаемую линию — только тогда она засчитывается в слово.

## Структура

- `docs/GAME_DESIGN.md` — дизайн-документ;
- `docs/ASSET_PLAN.md` — список визуальных и аудио-ассетов;
- `docs/references/` — утверждённые визуальные референсы;
- `godot/` — новый Godot-проект;
- `legacy/` — сюда можно положить исходную HTML/JS-версию без изменений.

## Утверждённый формат

- Desktop-first, 16:9;
- базовое разрешение: 1600×900;
- Godot 4, Compatibility / WebGL2;
- русский язык;
- UI без логотипа во время геймплея;
- панели с небольшим радиусом, без чрезмерно «мобильных» скруглений.
